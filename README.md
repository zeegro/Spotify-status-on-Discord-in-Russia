# 🎵 Spotify статус для Discord в России

Автоматический скрипт для обновления файла `hosts` с целью отображения статуса Spotify в Discord.

Скрипт получает список IP-адресов с `eu.geohide.ru`, проверяет их доступность по порту 443, безопасно обновляет `hosts` (сохраняя комментарии и структуру) и запускает Spotify.

## 🎯 Целевые домены
- `gew1-spclient.spotify.com`
- `api.spotify.com`
- `api-partner.spotify.com`

## 🚀 Как использовать

### Способ 1: Ручной запуск
1. Скачайте `Update-SpotifyHosts.ps1`.
2. Поместите в папку где он не будет мешаться.
3. Удалите все адреса связаные со Spotify в `C:\Windows\System32\drivers\etc\hosts`.
4. Нажмите по нему **правой кнопкой мыши** -> **Запуск от имени администратора** (или через PowerShell с флагом `-ExecutionPolicy Bypass`).
5. Дождитесь скрытого выполнения и автоматического открытия Spotify.

### Способ 2: Ярлык (Рекомендуется чтобы не возиться с правами каждый раз)
1. Скачайте `Update-SpotifyHosts.ps1`.
2. Поместите в папку где он не будет мешаться.
3. Удалите все адреса связаные со Spotify в `C:\Windows\System32\drivers\etc\hosts`.
4. Создайте на рабочем столе **Ярлык**.
5. В поле "Объект" вставьте:
   ```text
   powershell.exe -WindowStyle Hidden -Command "Start-Process powershell.exe -ArgumentList '-ExecutionPolicy Bypass -WindowStyle Hidden -File \"ПУТЬ К ФАЙЛУ\Update-SpotifyHosts.ps1"' -Verb RunAs"

- **(Обязательно замените "ПУТЬ К ФАЙЛУ" на реальный путь к файлу!)**
- **(Путь к фалу обязан быть без пробелов и кириллицы!)**
5. Назовите ярлык "Spotify", нажмите Готово.
6. (Опционально) Нажмите ПКМ на ярлык → Свойства → Сменить значок и выберите стандартную иконку Spotify.
7. Откройте ярлык и дождитесь выполнения и автоматического открытия Spotify.

# 🔄 Автозагрузка (Рекомендуется чтобы Spotify запускался сам при входе в систему)
1. Скачайте оба файла `Update-SpotifyHosts.ps1` и `Autostart.ps1`
2. Создайте **Ярлык** следуя **второму способу** установки.
3. Запустите `Autostart.ps1` **в той же папке, где находится созданный Ярлык**.
4. Скрипт сам создаст скрытую задачу в Планировщике задач и удалит оригинальный автозапуск Spotify в автозагрузке.
- *Примечание:* Повторный запуск `Autostart.ps1` удалит задачу и вернет оригинальный файл Spotify в автозагрузке.
